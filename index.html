Where do I get the model?

Easiest: download CorridorKey_v1.0.safetensors (~400 MB, huggingface.co/nikopueringer/CorridorKey_v1.0) and press Load .safetensors. The page builds the network from it locally; nothing is uploaded.

Alternative (faster, tested path): export an ONNX once with the original repo:

pip install torch timm safetensors onnx onnxruntime
python export_onnx.py --repo /path/to/CorridorKey-main \
  --weights CorridorKey_v1.0.safetensors \
  --img-size 1024 --out CorridorKey.onnx --verify

WebGPU needs Chrome/Edge over HTTPS (or localhost). 2048 is the native size but very heavy for browsers.
